## Title

DSTAR — Agent-Native Document Review with WebMCP | Demo

## Description

DSTAR is an HTML-first review workspace for documents created and revised by
AI agents. People review exact selections, discuss changes in comment threads,
and explicitly decide which revision becomes current.

This 1:47 demo shows:

- one review model across documents, rich HTML, slides and UI design specs;
- an external agent creating and revising the artifact;
- WebMCP carrying the live page context to the agent;
- editable comment drafts that never post automatically; and
- a pending revision that only the Owner can accept or reject.

Live project: https://www.thinkofu.ai/dstar/

Source code: https://github.com/x-prime-ai/dstar

Built for the WebMCP Challenge. Licensed under Apache-2.0.
