01 / PREMISE

Most agent workflows end in a file and a chat log. DSTAR adds the missing layer: a human-readable review contract around the file. Comments remain attached to what was seen. Proposed revisions remain inspectable. Acceptance remains a deliberate human action.

05 / DETAILS

A few precise answers

Is DSTAR a new document renderer?

No. The browser renders the canonical HTML and CSS. DSTAR defines how those bytes are validated, versioned, reviewed, and reopened.

Do comments automatically resolve after an edit?

No. DSTAR preserves the discussion state separately. A recovered anchor can remain open until a person intentionally resolves it.

Can an agent accept its own proposal?

No. Agent tools can read, draft, reply, and propose within scope; document decisions remain explicit human actions.
